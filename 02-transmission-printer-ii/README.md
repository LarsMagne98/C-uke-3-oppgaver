# Oppgave 02 — Transmission Printer II

**Hovedfokus:** overloads med ny signatur

Bygg videre på overload-idéen, men denne gangen skal du selv bestemme signaturen til en tredje overload.

Programmet trenger tre varianter:
1. Bare melding.
2. Avsender + melding.
3. Avsender + melding + en verdi som gjør at meldingen kan merkes med prioritet **eller** repeteres flere ganger.

Krav:
- Alle metodene skal hete `PrintTransmission`.
- Signaturene må være forskjellige.
- Ikke løs det med tre metoder med forskjellige navn.

## Kjøring

```bash
dotnet run
```
