# Oppgave 04 — Moon Parcel

**Hovedfokus:** constructor + properties

Lag en `Parcel`-klasse der identiteten må være gyldig fra opprettelsesøyeblikket.

Constructoren skal ta inn:
- `trackingCode`
- `destination`
- `weight`

og sette properties.

Opprett minst tre parcels med constructor-argumenter og skriv dem ut.

Ikke sett disse tre verdiene manuelt etter `new`; de skal sendes inn gjennom constructoren.

## Kjøring

```bash
dotnet run
```
