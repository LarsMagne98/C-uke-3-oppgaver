# Oppgave 08 — Move the Model

**Hovedfokus:** klasse i egen fil

Denne oppgaven handler bare om filstruktur.

`Probe`-klassen ligger foreløpig nederst i `Program.cs`. Flytt hele klassen til en ny fil kalt `Probe.cs`.

Krav:
- Programmet skal oppføre seg identisk etter flyttingen.
- Ikke endre klasseinnholdet med mindre det er nødvendig.
- `Program.cs` skal til slutt bare inneholde programflyten.

## Kjøring

```bash
dotnet run
```
