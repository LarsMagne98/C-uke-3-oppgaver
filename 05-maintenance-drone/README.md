# Oppgave 05 — Maintenance Drone

**Hovedfokus:** instance methods

`Drone` skal eie data om seg selv og kunne svare på spørsmål om egen tilstand.

Fullfør:
- `Describe()` → returnerer en beskrivelse av akkurat denne dronen
- `NeedsService()` → returnerer `true` når `FlightHours >= 100`

Opprett minst tre droner med ulike verdier og kall de samme instance-metodene på alle.

## Kjøring

```bash
dotnet run
```
