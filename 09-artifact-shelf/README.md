# Oppgave 09 — Artifact Shelf

**Hovedfokus:** List<T> med objekter

Opprett minst fire `Artifact`-objekter og legg dem i en `List<Artifact>`.

Deretter:
- skriv `.Count`
- iterer over listen
- skriv `Name`, `Origin` og `Risk` for hvert objekt
- legg til ett nytt artifact etter at listen allerede er opprettet

Dette er første eksplisitte øvelse på en collection av **egne objekter**.

## Kjøring

```bash
dotnet run
```
