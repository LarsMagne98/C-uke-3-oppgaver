# Oppgave 03 — Unknown Creature

**Hovedfokus:** første klasse og objekter

Fullfør `Creature`-klassen og opprett minst tre forskjellige objekter.

Hvert creature skal ha:
- `Name`
- `Species`
- `Energy`

I `Program.cs`:
- opprett tre objekter med `new`
- gi dem ulike verdier
- skriv egenskapene deres

Poenget er å se forskjellen på **klassen** som mal og hvert **objekt** som en konkret instans.

## Kjøring

```bash
dotnet run
```
